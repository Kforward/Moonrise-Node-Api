# 变更异同分析

## 目录职责
- 本目录存放版本、需求、接口、数据库或功能级异同分析。
- 长期稳定流程沉淀到 `docs/ai-agent/`。
- 设计权威事实仍以 `backend_ai_docs/` 为准；本目录只记录某次变化相对既有逻辑的差异。

## 建议命名
- `<date>-<feature>-diff.md`
- `<branch>-<feature>-diff.md`
- `<version>-<feature>-diff.md`

## 单篇模板
### 背景
说明该变化来自哪次需求、版本、接口或修复。

### 复用逻辑
列出现有模块、接口、表、仓储、测试或文档中可复用的部分。

### 差异点
说明行为、数据结构、接口、权限、安全、同步或部署差异。

### 兼容影响
说明旧客户端、旧数据、已有 API、OpenAPI 契约、迁移和测试是否受影响。

### 风险
列出可能的行为回归、数据一致性、安全、性能或联调风险。

### 验证清单
列出需要运行的命令、接口用例、数据库检查或手工验证步骤。
