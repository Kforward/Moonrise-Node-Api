# Project Routing

用于恢复项目、理解当前状态、路线、决策和项目边界。

| 任务 | 读取 |
|---|---|
| 开始新会话或恢复工作 | `docs/STATUS.md`、`docs/HANDOFF.md` |
| 理解项目目标、范围和关键约束 | `docs/PROJECT.md`、`README.md` |
| 检查近期优先级 | `docs/ROADMAP.md`、`backend_ai_docs/07_migration_roadmap.md` |
| 理解决策背景 | `docs/DECISIONS.md` |
| 查看业务、架构、API、数据库、安全设计地图 | `backend_ai_docs/README.md` |
| 阶段结束后更新项目状态 | `docs/STATUS.md`、`docs/HANDOFF.md`，必要时更新 `docs/ROADMAP.md` 和 `docs/DECISIONS.md` |

任务类型变化时再回到 `docs/AGENT_INDEX.md`。
