# 路线图

本文件只记录协作视角的近期路线；后端改造的详细阶段和优先级以 `backend_ai_docs/07_migration_roadmap.md` 为准。

## Now
- 维护多 Agent 协作文档入口，保证新 Agent 可按 `AGENTS.md` 和 `docs/AGENT_INDEX.md` 接手。
- 扩展 PostgreSQL 仓储边界测试，覆盖幂等、同步日志、分页、软删除和错误路径。
- 评估业务写入、同步日志、审计日志和幂等快照的事务一致性收敛方案。

## Next
- 引入 Redis 或等价共享存储限流适配，支持多实例部署。
- 补齐刷新 token 失败、批量同步失败、隐私解密失败等安全失败路径审计。
- 设计并落地 key wrap 托管能力，支持恢复密钥、可信设备换机和不可恢复 reset。
- 收敛分页契约和 PostgreSQL 查询实现，减少内存切页。
- 根据前端联调反馈更新 OpenAPI 契约和业务规则文档。

## Later
- 可选开放提醒队列或实时通知能力。
- 根据实际运营需求完善发布、回滚、备份恢复演练和监控告警文档。

## 暂不做
- 不把所有周期预测计算迁到后端。
- 不引入与 Moonrise 当前业务无关的示例模块。
- 不在没有独立测试库的情况下运行会写入或清理 PostgreSQL 数据的测试。
